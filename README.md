# 回忆成调

免费、本地运行的回忆音乐创作网页，无外部 API、无运行依赖。

## 启动

在项目目录运行 `npm start`，打开 http://127.0.0.1:4175 。需要现代版本 Node.js，以及支持 Web Audio 的浏览器。也可以将 dist 目录部署到任意静态网站托管服务。请通过 HTTP 使用，不要直接双击 index.html。

## 已实现

- 单人、情侣、朋友模式；双人模式在同一设备填写。
- 六步创作：模式、故事、心情、风格与乐器、结尾、确认。
- 约 39–55 秒确定性规则作曲，四个独立声部，实时开关和音量控制。
- 三种声音风格，六种心情，三种情绪走向。
- 本地收藏、草稿、WAV 下载、JSON 作品备份与导入。
- 响应式页面和键盘焦点样式。

## 海洋蓝改版

新增海洋蓝与黑色主题、流动光影和黑胶卡片。黑胶中心使用本地 SVG 插画生成器，按回忆中的海岸、校园、城市、山林、雨夜等关键词及文字种子绘制；不调用付费图片服务。新增钢琴、吉他、小提琴独立合成声部，忧郁、焦虑、孤独、兴奋、释然情绪，以及由真实音频频谱驱动的播放动画、暂停续播和进度跳转。原有收藏和备份沿用原存储键，可继续读取。

文字用来形成音乐种子，不做语义理解。音色使用振荡器合成，钢琴为键盘风格合成音色，并非真实钢琴采样。相同参数可还原乐谱，不承诺全球唯一旋律。所有故事与作品留在浏览器；清除网站数据会移除本地收藏，请导出备份。异地邀请与云同步未包含在此版本。

## 检查

`npm run check` 检查语法，`npm test` 验证还原性、作曲参数和音频文件编码。
