# 回忆成调

把故事、心情和颜色写成可播放、可编曲、可导出的旋律。音乐在浏览器本地合成，无需付费音乐 API。

## 当前状态

2.0 试用版本，支持 Windows 本地使用与独立服务器部署。本地自动化测试已通过；公网部署、真实 PostgreSQL 连接和跨设备手机验收尚未完成。

## 功能

- 六步创作流程，七种音乐风格、十一种心情、四种落幕方式。
- 七个独立声部，音量、速度、多片段出入场、淡变和编曲预设。
- 海洋蓝与黑色主题、回忆颜色、生成式 SVG 封面和音频频谱动画。
- 播放、暂停、跳转，WAV 音频导出和 JSON 作品备份、导入。
- 访客收藏与草稿；账号注册、登录和账号作品保存。
- 在线模式支持双人邀请房间，双方同意分享后提交各自的回忆。
- 可选 AI 编曲助手：理解故事，预览并一键应用心情、风格、速度、乐器与结尾建议。

默认文字用于生成确定性的音乐种子；可选 AI 助手可理解故事并推荐编曲参数，需用户确认后应用；音色由合成器生成，并非真实乐器采样。相同参数可还原乐谱，不承诺全球唯一旋律。

## 从源码运行

需要 Node.js 24.14 或更高版本，以及支持 Web Audio 的现代浏览器。

```sh
npm ci
npm start
```

打开 http://127.0.0.1:4175 。默认仅监听本机，数据存入 `.data/recall.sqlite`，本机模式不提供远程邀请。必须运行 Node.js 服务；仅上传 `dist/` 到静态托管不能提供完整账号和房间功能。

## Windows 免安装版

完整安装包包含 Node.js 运行环境，解压后双击 `启动网页.cmd`，使用时保留启动窗口。源码仓库不包含运行环境和安装包。直接下载源码时，先安装 Node.js 24.14 或更高版本并运行 `npm ci`，之后也可以双击 `启动网页.cmd`，脚本会使用系统安装的 Node.js。

Windows 版支持同机双人创作，不提供跨电脑实时房间或云端同步。说明见 [Windows 使用说明](WINDOWS-README.html)。安装包应通过 GitHub Release 单独分发。

## 数据与隐私

访客作品保存在当前浏览器，清除网站数据会丢失，请定期导出 JSON。账号保存的作品写入服务数据库，本地账号仅在本机生效。房间回答提交后会向另一位参与者展示，房间有效期为 30 天。在线运营前还需完善数据库备份、账号及数据删除入口与隐私说明。

仓库排除本地数据库、环境变量、依赖、运行环境、打包产物和工作输出。不要将真实密码、连接串或用户数据提交到 Git。

## AI 编曲助手

在创作第二步填写故事后，勾选发送同意，点击“分析故事，推荐编曲”。助手会预览心情、风格、速度、结尾、乐器和推荐理由；点击“应用这份编曲建议”后替换这些参数并重置混音，故事和标题保留。后续仍可手动调整。双人本机创作可分别推荐两人的心情；远程房间内暂未提供此入口。

本功能接入支持 Chat Completions、JSON Object 输出的模型服务，不生成音频。接口格式参考 [DeepSeek 官方 JSON 输出文档](https://api-docs.deepseek.com/guides/json_mode/)。模型名称请填写服务商当前提供的模型 ID。

在项目根目录创建 `.env`（或在托管平台设置私密环境变量），填入：

```dotenv
AI_API_KEY=你的模型服务密钥
AI_BASE_URL=https://api.deepseek.com
AI_MODEL=你选择的模型ID
```

`AI_BASE_URL` 填 API 基地址，不包含 `/chat/completions`，必须使用 HTTPS；其他兼容服务按其文档填写（部分服务需要以 `/v1` 结尾）。三个值齐全后重启服务。源码 `npm start` 和 Windows 启动器均读取根目录 `.env`；Docker Compose 会传入这三个变量；Render 请在环境设置中添加。不要把密钥写进 `dist/` 或提交到 Git。未配置或调用失败时仍可手动创作。

在线模式需先登录，本机模式无需登录。每个账号（本机按来源地址）每小时最多尝试 10 次，服务最多同时处理 3 个请求，25 秒超时；限流保存在内存，重启会重置。多实例部署需要共享额度管理。模型服务可能计费，请在服务商侧设置预算。

发送前须明确同意；双人故事须获得另一位参与者同意。接口仅向配置的模型服务发送故事和模式，不发送账号、标题、密钥以外的认证信息。故事会离开本设备，服务商的数据处理规则由部署者选用的服务决定；本应用不在数据库中额外保存 AI 请求或推荐理由。当前自动化验证使用模拟模型响应，实际效果仍需配置真实服务后验收。
