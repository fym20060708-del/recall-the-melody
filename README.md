# 回忆成调

免费、本地运行的回忆音乐创作网页，无外部 API、无运行依赖。

## 启动

在项目目录运行 `npm start`，打开 http://127.0.0.1:4175 。需要现代版本 Node.js，以及支持 Web Audio 的浏览器。也可以将 dist 目录部署到任意静态网站托管服务。请通过 HTTP 使用，不要直接双击 index.html。

## 已实现

- 单人、情侣、朋友模式；双人模式在同一设备填写。
- 六步创作：模式、故事、心情、风格与乐器、结尾、确认。
- 确定性规则作曲，七个独立声部，实时开关、独立音量及出入场控制。
- 七种风格：钢琴、电子、氛围、R&B、民谣、抒情芭乐、摇滚；十一种心情，四种落幕方式。
- 本地收藏、草稿、WAV 下载、JSON 作品备份与导入。
- 响应式页面和键盘焦点样式。

## 海洋蓝改版

新增海洋蓝与黑色主题、流动光影和黑胶卡片。黑胶中心使用本地 SVG 插画生成器，按回忆中的海岸、校园、城市、山林、雨夜等关键词及文字种子绘制；不调用付费图片服务。新增钢琴、吉他、小提琴独立合成声部，忧郁、焦虑、孤独、兴奋、释然情绪，以及由真实音频频谱驱动的播放动画、暂停续播和进度跳转。原有收藏和备份沿用原存储键，可继续读取。

文字用来形成音乐种子，不做语义理解。音色使用振荡器合成，钢琴为键盘风格合成音色，并非真实钢琴采样。相同参数可还原乐谱，不承诺全球唯一旋律。所有故事与作品留在浏览器；清除网站数据会移除本地收藏，请导出备份。异地邀请与云同步未包含在此版本。

## 检查

新增“回忆颜色”：六种预设与自定义色，支持创作时选择、作品页实时换色、收藏卡直接换色，并随 JSON 备份导出。颜色不参与作曲种子，不会改变已有旋律。播放器改为音频频谱驱动的旋律星轨，支持圆环拖动、方向键与章节节点跳转，保留辅助技术可用的进度滑块。全站新增漂浮音符与五线谱光带，并遵循减少动态效果设置。

`npm run check` 检查语法，`npm test` 验证还原性、作曲参数和音频文件编码。

## 回忆编曲台

乐器的出场、离场使用相对时长位置（0–100%），切换速度后仍保持章节位置。音量范围为 0–150%，进出片段有短淡变。试听通过 AudioParam 自动化执行，WAV 导出使用相同包络；作品备份包含 mix 与 tempo，可重新导入。速度范围 60–150 BPM，通过重新渲染音符起始时间与时值实现，音高不变。

新增“渐进展开”“双人对话”“私密独白”编曲预设，以及每个乐器的“此刻高光”、撤回调整和恢复整段演奏。预设安排已启用乐器的出场，双人对话建议启用钢琴、吉他和小提琴。

网页已公开访问。右上角“分享网页”提供公开链接的复制和系统分享，分享的是创作空间，不包含本地回忆。无需账号和付费 API。音色仍为本地合成器音色，风格是规则化编曲，并非录音室级真实乐器采样。
