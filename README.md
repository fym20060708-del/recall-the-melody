# 回忆成调

把故事、心情和颜色写成可播放、可编曲、可导出的旋律。音乐在浏览器本地合成，无需付费音乐 API。

## 当前状态

2.0 试用版本，支持 Windows 本地使用与独立服务器部署。本地自动化测试已通过；公网部署、真实 PostgreSQL 连接和跨设备手机验收尚未完成。

## 功能

- 六步创作流程，七种音乐风格、十一种心情、四种落幕方式。
- 七个独立声部，音量、速度、多片段出入场、淡变和编曲预设。
- 海洋蓝与黑色主题、回忆颜色、生成式 SVG 封面和音频频谱动画。
- 播放、暂停、跳转，WAV 音频导出和 JSON 作品备份、导入。
- 访客收藏与草稿；账号注册、登录和账号作品保存。
- 在线模式支持双人邀请房间，双方同意分享后提交各自的回忆。

文字用于生成确定性的音乐种子，不做语义理解；音色由合成器生成，并非真实乐器采样。相同参数可还原乐谱，不承诺全球唯一旋律。

## 从源码运行

需要 Node.js 24.14 或更高版本，以及支持 Web Audio 的现代浏览器。

```sh
npm ci
npm start
```

打开 http://127.0.0.1:4175 。默认仅监听本机，数据存入 `.data/recall.sqlite`，本机模式不提供远程邀请。必须运行 Node.js 服务；仅上传 `dist/` 到静态托管不能提供完整账号和房间功能。

## Windows 免安装版

完整安装包包含 Node.js 运行环境，解压后双击 `启动网页.cmd`，使用时保留启动窗口。源码仓库不包含运行环境和安装包，直接下载源码请按上面的方式运行。

Windows 版支持同机双人创作，不提供跨电脑实时房间或云端同步。说明见 [Windows 使用说明](WINDOWS-README.html)。安装包应通过 GitHub Release 单独分发。

## 在线部署

- [Render + PostgreSQL 部署说明](DEPLOY-FREE.md)
- [阿里云 Docker 部署说明](DEPLOY-ALIYUN.md)

已提供 `render.yaml`、`Dockerfile`、`compose.yaml` 和环境变量示例 `.env.example`。公网环境需要 HTTPS；数据库密码只配置到托管平台的私密环境变量。临时磁盘托管必须使用外部 PostgreSQL。

上线前需要验证真实数据库连接、两台设备的账号隔离与邀请协作、手机音频播放与导出，以及服务重启后的数据保留。部署文档中的套餐与额度以平台实际规则为准。

## 检查

```sh
npm run check
npm test
```

测试覆盖音乐还原、混音与 WAV 编码、账号与会话、房间权限、SQLite 持久化和 PostgreSQL 适配。适配器单元测试不代替真实 PostgreSQL 联调。GitHub Actions 会在推送及 Pull Request 时运行检查。

## 文件结构

| 路径 | 用途 |
| --- | --- |
| `dist/` | 直接提供给浏览器的前端源码与样式 |
| `backend/` | 账号、收藏、房间 API 与数据库适配 |
| `server.mjs` | HTTP 服务入口 |
| `tests/` | 自动化测试 |
| `scripts/` | 语法检查与 Windows 启动脚本 |
| `.github/workflows/` | 持续集成检查 |

## 数据与隐私

访客作品保存在当前浏览器，清除网站数据会丢失，请定期导出 JSON。账号保存的作品写入服务数据库，本地账号仅在本机生效。房间回答提交后会向另一位参与者展示，房间有效期为 30 天。在线运营前还需完善数据库备份、账号及数据删除入口与隐私说明。

仓库排除本地数据库、环境变量、依赖、运行环境、打包产物和工作输出。不要将真实密码、连接串或用户数据提交到 Git。
