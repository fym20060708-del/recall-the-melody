RECALL THE MELODY / WINDOWS EDITION

让回忆，在你的电脑里有回声。

不用购买服务器，不用配置数据库。解压，双击，开始创作。适用于 Windows 10 / 11 的 64 位电脑，建议使用新版 Edge 或 Chrome。

在 Windows 上打开

01先完整解压

右键压缩包，选择“全部解压缩”。不要在压缩包预览中直接运行。

02双击「启动网页.cmd」

保留 dist、backend、scripts 和 runtime 文件夹与启动文件放在一起。已经内置运行环境，无需安装。

03把故事写成音乐

浏览器会自动打开。回答问题、选择情绪和乐器，就能生成并调整旋律。

如果浏览器没有自动打开，请用 Edge 或 Chrome 访问 http://127.0.0.1:4175/。使用期间请保留启动窗口，结束后关闭即可。

能做些什么？

  • 单人、情侣、朋友模式；双人模式在同一台电脑上分别填写故事与心情。
  • 七种音乐风格、十一种情绪、四种落幕方式；海洋蓝界面、动态星轨播放器和自选颜色黑胶卡片。
  • 每种乐器可安排多个演奏片段，并调整速度、音量和进出场位置。
  • 收藏作品、下载 WAV 音频，或导出 JSON 作品备份供另一台电脑导入。

保存、账户和分享

不用注册也可以创作。访客收藏与草稿保存在当前浏览器；可选的“本机账户”保存在此文件夹的 .data 数据库中，只在这台电脑可用。没有云端同步，也没有跨电脑实时邀请房间。请勿删除 .data 文件夹；换电脑前请备份作品。

想让朋友使用整个项目：把你收到的原始 回忆成调-Windows版.zip 发给对方。不要直接打包你使用过的文件夹，以免把本机账户和私人回忆一起发出去。

想分享一段旋律：在作品页选择“下载音频”或“备份作品”，发送导出的文件。127.0.0.1 只代表当前电脑，不能作为公开网址分享。

打不开时

  • 提示“缺少运行环境”：重新完整解压，不要只复制启动文件。
  • 提示“端口已被占用”：关闭先前的启动窗口，再重试。其他程序占用 4175 时，也需先释放端口。
  • 没有声音：点击播放按钮，检查系统与浏览器音量；换用最新版 Edge 或 Chrome。
  • 写入失败：把解压文件夹放到有写入权限的普通目录，例如“文档”。不要放到系统程序目录。

音乐由浏览器本地合成，使用时不需要网络。音色为合成器模拟；浏览器仍需用户点击才能播放声音。此包不包含作者的账号、作品数据库或云平台密钥。
